## Design Context

### Users
OpenBee operators and technical teams who run AI workers on their own machines or servers. They use the web console to create workers, assign work, inspect task and session history, and debug automation runs.

### Brand Personality
Direct, operational, technical. The interface should feel dependable, efficient, and quietly confident rather than playful or decorative.

### Aesthetic Direction
A data-dense control console with strong scanability, restrained neutral surfaces, subtle motion, and crisp typography. Favor structured views such as tables and lists for operational pages, while keeping light and dark themes visually consistent.

### Design Principles
- Optimize for fast scanning and state recognition.
- Prefer structured data views for management workflows.
- Keep metadata subdued and reserve emphasis for status and primary actions.
- Reuse existing UI primitives and motion patterns instead of introducing a new visual language.
- Keep dense layouts responsive and overflow-safe on smaller screens.
